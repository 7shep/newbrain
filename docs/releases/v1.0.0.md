A personal "digital brain" for working with Claude Code: a folder of plain markdown notes that Claude reads instead of re-deriving context every session, plus a small local app (Mac, browser and phone) to browse and act on them.

## Set it up with one prompt

**Pick the one that fits you:**
- **Starting fresh:** use the prompt below. Claude interviews you, writes your first notes, connects itself, and ends with a link to open on your phone.
- **Already keep notes** in Obsidian, Notion, Apple Notes or a markdown folder: use [**From the notes you already have**](https://github.com/zacfink/brain#from-the-notes-you-already-have) in the README instead. Claude builds your Brain from them and never touches the originals.

**Starting fresh:** paste this into [Claude Code](https://claude.com/claude-code) and answer its questions.

```text
Set up Brain (https://github.com/zacfink/brain) for me from scratch. Work through it step by step, tell me what
each step is for in one line, and ask me before anything that touches my accounts.

1. Clone https://github.com/zacfink/brain.git into ~/Notes/.brain (keep anything already in ~/Notes), link
   ~/Notes/.brain/bin/brain into ~/.local/bin (create it, and add it to my shell profile's PATH if it isn't
   there), and read ~/Notes/.brain/README.md and FORMATS.md before going on.
2. Interview me briefly: my name, what I do, my active projects, people I work with, anything due in the next two
   weeks. Then write my first notes in the FORMATS.md shapes: me.md, now.md, one page per project, people pages,
   nudges.md, ideas.md, inbox.md and claude/habits.md (two or three habits from what I told you, status "proposed").
   If you can see my projects folder, calendar or email, use them to fill gaps, and say what you took from where.
3. Connect yourself: add the SessionStart hook from the README to ~/.claude/settings.json (merge, don't overwrite),
   and add the README's standing instructions to my CLAUDE.md. Then run python3 ~/Notes/.brain/build.py.
4. Start the app with `brain` and check it opens at http://127.0.0.1:4747. On a Mac, ask me whether I want it as
   an app; if yes, run ~/Notes/.brain/mac/build.sh (needs Xcode's command line tools) to make ~/Applications/Brain.app.
5. Phone (ask me first): add ".brain/" to ~/Notes/.gitignore, create a PRIVATE GitHub repo "notes" with gh,
   add docs/notes-workflow.yml as .github/workflows/brain.yml plus phone/queue/.gitkeep, commit and push, and wait
   for the Action's first run to write phone/state.json.
6. Walk me through making the phone key (README → On your phone, step 3); I paste it to you. Then give me my
   one-tap install link: https://zacfink.github.io/brain/mobile/#c= followed by base64 of
   {"repo":"<me>/notes","token":"<key>"}. Tell me to open it in Safari, tap Share → Add to Home Screen, and treat
   the link like a password. Don't save the key anywhere.
7. Finish with a short list: what's set up, what I should try first, and anything that didn't work.
```

## Or try it in 30 seconds

```bash
git clone https://github.com/zacfink/brain.git
cd brain
python3 app/server.py --notes example      # opens http://127.0.0.1:4747
```

`example/` is a fictional student's notes. Python 3.9+, standard library only, no build step. macOS, Windows and Linux.

## What's in 1.0

- **The board:** cover story, Up next, Notes to self, projects, people, ideas, habits, and "Everything we've done", laid out as adaptive tiles you can rearrange (drag on the Mac, hold-then-tap on the phone).
- **How Claude adapts to you:** habits Claude follows every session; it proposes new ones and you switch them on.
- **Custom tiles:** any `tiles/*.md` becomes a tile, optionally kept live by a refresh script (`/brain-tile` builds one).
- **Map:** your notes' knowledge graph from graphify, drawn in the app's theme and searchable, on Mac and phone.
- **Phone app:** a home-screen app that works with your laptop off, using a private GitHub repo as the backend: capture, mark nudges done, ask your notes by voice, plus an iOS widget (Scriptable).
- **Mac app:** `mac/build.sh` makes `Brain.app`, including the see-through Glass theme.
- **Themes:** five families (Classic, Brain, Phosphor, Riso, Swiss, plus Glass on the Mac), synced between devices if you want.
- **Background agents and routines:** captures can start a headless Claude Code agent; your scheduled routines show with their last runs.
- **Stats and calibration:** prompts, sessions, tokens and tool calls from Claude Code's transcripts, and a score for how well Claude predicts what you'll want.
- **Decision freshness:** key decisions get a check-by date and resurface when it passes.

## Since the last commits

- Phone: 8 bug fixes, including the widget showing no events, the Map missing in tiles layout, and actions that could be left unsent (#8).
- Security: a tile's `refresh:` command now runs only if it's listed in `~/.config/brain/refresh-allow` on your Mac, so a tile pushed to your notes repo can't run code on your computer. **If you already have live tiles, add their commands to that file.** Also: sync errors are shown instead of silently dropping changes, a broken `layout.json` falls back cleanly, and the Map republishes after a graphify rebuild (#9).
