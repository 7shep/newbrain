# Routines in Brain Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Brain shows the user's Claude Code routines (cloud scheduled agents), lets the Mac app run, pause and resume them, flags ones that look unnecessary, and suggests new ones inside Capture; the phone shows status read-only.

**Architecture:** Brain can't call the routines API itself (it needs the Claude login that only Claude Code holds), so a new `app/routines.py` runs headless `claude -p` with only the `RemoteTrigger` tool allowed, asks for compact JSON, and caches it in `claude/routines.json` in the notes. `server.state()` includes that file, so the desktop app, `phone.py` and the phone all read the same snapshot. Creating a routine is a Capture kind (`routine`) that goes through the existing Agents queue with its own prompt and tool list, so phone captures park and run on the Mac like every other capture.

**Tech Stack:** Python 3 standard library (app), plain HTML/JS (`app/index.html`, `mobile/index.html`), `unittest`, Claude Code CLI.

**Spec (agreed in chat with the user, 2026-10-19):**
- Desktop Routines tile: running routines with plain-words schedule, last run and ✓/✗, **Run now** and **Pause**; paused ones collapsed under "Paused (n)" with **Resume**; a one-line "looks unnecessary: <reason>" hint on routines Claude flags. The API can't delete, so dead ones are only collapsed.
- Suggestions live in **Capture** (desktop ⌘K palette and phone capture sheet): up to 3 suggestion chips; tapping one fills Capture with kind **Routine**. Typing your own text with kind Routine works too.
- A captured routine is created **paused**; the user resumes it in the Routines tile. That is the confirm step.
- Phone: read-only Routines card (name, ✓/✗, last run). No buttons.
- Refresh when the desktop app loads and the snapshot is older than 10 minutes, and after every action.

## Global Constraints

- Standard library only; no new dependencies, no build step (README promise).
- Headless calls use the same flags as `agents.claude_command`: `--setting-sources project --permission-mode dontAsk -p`, prompt on stdin.
- Routine calls allow **only** `RemoteTrigger`; the suggest call allows **only** `Read`, `Glob`, `Grep`. Agents for other capture kinds never get `RemoteTrigger`.
- Status/act calls use `--model haiku` (the list response is large); suggest/create use the default model.
- Snapshot path: `claude/routines.json`. Freshness window: 10 minutes. Suggestions regenerate at most once per calendar day.
- Brain is a public repo: tests and code carry no personal routine names or prompts.

## Review Focus

1. Claude replies with prose around the JSON, or with no JSON at all → keep the old snapshot and surface `error`, never wipe the list.
2. Never logged in / `claude` missing → tile shows "Couldn't reach your routines: <reason>", the rest of Brain loads normally.
3. Two refreshes at once (two tabs, or load + button) → one runs, the other returns the current snapshot.
4. A notes folder with no `claude/routines.json` (new users, phone before first Mac refresh) → tile and phone card hidden, Capture shows no suggestion chips.
5. An action on an id that's no longer in the list → 404-style error toast, snapshot refreshed.

### Task 1: `app/routines.py` — snapshot, refresh, actions, suggestions

**Files:**
- Create: `app/routines.py`
- Test: `tests/test_routines.py`

**Interfaces:**
- Produces:
  - `parse_json(text: str) -> dict` — the first `{...}` object in `text` (tolerates prose and ```json fences); raises `ValueError` if none.
  - `class Routines(notes: str, command: list[str] | None = None, suggest_command: list[str] | None = None)`
    - `.load() -> dict | None` — contents of `claude/routines.json`, `None` if missing.
    - `.stale(minutes: int = 10) -> bool` — no snapshot, or `checked` older than `minutes`.
    - `.refresh() -> dict` — runs the status prompt; on success writes `{"checked": iso, "routines": [...], "suggestions": prev, "suggested": prev, "error": ""}`; on failure keeps the previous snapshot and sets `error`. Non-blocking lock: if a refresh is already running, returns `.load()`.
    - `.act(rid: str, action: str) -> dict` — `action` in `("run", "pause", "resume")` else `ValueError`; `rid` must be in the snapshot else `KeyError`; runs the act prompt, then `.refresh()`.
    - `.suggest(force: bool = False) -> dict` — skips when `suggested == today` unless `force`; stores `suggestions` (≤3 of `{"title","schedule","text"}`) and sets each routine's `why_pause` from the reply's `pause` list (`[{"id","reason"}]`).
  - Routine item shape: `{"id","name","schedule","enabled": bool,"last_run": "YYYY-MM-DD HH:MM" or "","ok": bool | None,"next_run": str,"why_pause": str}`.
  - `routine_command() -> list[str]`, `suggest_command() -> list[str]`, `CREATE_PROMPT: str` (used by Task 2).

```python
def test_parse_json_ignores_prose_and_fences(self):
    self.assertEqual(parse_json('Sure!\n```json\n{"a": 1}\n```'), {"a": 1})
    with self.assertRaises(ValueError):
        parse_json("no json here")

def test_refresh_writes_snapshot(self):
    r = Routines(self.notes, command=fake('{"routines":[{"id":"t1","name":"Daily","schedule":"Daily 7am","enabled":true,"last_run":"2026-10-19 07:00","ok":true,"next_run":"2026-10-20 07:00"}]}'))
    snap = r.refresh()
    self.assertEqual(snap["routines"][0]["id"], "t1")
    self.assertEqual(snap["error"], "")
    self.assertEqual(r.load()["routines"][0]["why_pause"], "")
    self.assertFalse(r.stale())

def test_bad_reply_keeps_old_list(self):          # Review Focus 1
    good = Routines(self.notes, command=fake('{"routines":[{"id":"t1","name":"A"}]}')); good.refresh()
    snap = Routines(self.notes, command=fake("I couldn't do that")).refresh()
    self.assertEqual([x["id"] for x in snap["routines"]], ["t1"])
    self.assertTrue(snap["error"])

def test_missing_claude_sets_error(self):         # Review Focus 2
    snap = Routines(self.notes, command=["/no/such/claude"]).refresh()
    self.assertIn("wasn't found", snap["error"])

def test_act_validates(self):                     # Review Focus 5
    r = Routines(self.notes, command=fake('{"routines":[{"id":"t1","name":"A"}]}')); r.refresh()
    with self.assertRaises(ValueError): r.act("t1", "delete")
    with self.assertRaises(KeyError): r.act("gone", "run")

def test_suggest_once_a_day_and_flags(self):
    r = Routines(self.notes, command=fake('{"routines":[{"id":"t1","name":"A"}]}'),
                 suggest_command=fake('{"suggestions":[{"title":"Week plan","schedule":"Sun 6pm","text":"Every Sunday 6pm, plan my week"}],"pause":[{"id":"t1","reason":"replaced"}]}'))
    r.refresh(); snap = r.suggest()
    self.assertEqual(snap["suggestions"][0]["title"], "Week plan")
    self.assertEqual(snap["routines"][0]["why_pause"], "replaced")
    self.assertEqual(r.suggest(), snap)           # same day: no second call
```

- [ ] **Step 3: Implement `app/routines.py`**

Prompts (exact wording is the implementer's; these must be in them):
- status: call `RemoteTrigger` with `action: list`; reply with only `{"routines":[...]}` in the item shape; `schedule` in plain words in the user's local time, honouring any "only run if the local hour is N" guard in a routine's prompt; `ok` false when the last run has a real failure reason, null when it never ran.
- act: `run` → `RemoteTrigger action=run trigger_id=<id>`; `pause`/`resume` → `action=update` with body `{"enabled": false|true}`; reply `{"ok": true}`.
- suggest: read `INDEX.md`, `now.md` and `claude/routines.json`; reply `{"suggestions": [...≤3], "pause": [...]}`; suggest only things a cloud routine with Gmail/Calendar/GitHub could really do; flag running routines that duplicate another or whose subject is finished.
- `CREATE_PROMPT` (format arg `text`): create a routine with `RemoteTrigger action=create` for the request; copy the request-body shape from an existing routine (`action=get` on one from `list`), change name, prompt and cron; **always `enabled: false`**; end with ≤3 lines: name, schedule in plain words, "Created paused. Resume it in Brain's Routines tile."

Write the snapshot through a temp file + `os.replace` (same pattern as `Agents._write`). `routine_command()` = claude flags + `--model haiku --allowedTools RemoteTrigger`; `suggest_command()` = claude flags + `--allowedTools Read Glob Grep`. Timeout 5 minutes.
