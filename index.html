Brain.

A folder of plain markdown notes that Claude Code reads every session, so it stops re-deriving who you are and what you're working on. Plus a small app to browse and act on them, on your Mac, in the browser and on your phone.

Set it up with one prompt Download the latest release Source on GitHub

What it does

Cover storyClaude writes a magazine-style headline about your week after real work.
Habits Claude followsClaude proposes habits; you switch each one on or off.
Notes to selfReminders Claude adds only when they help. Done, snooze, or "not doing this".
⌘K captureType a thought, to-do or person. Claude files it into the right note next session.
Custom tilesAny tiles/*.md becomes a tile, optionally kept live by a script.
Plain filesEverything is markdown on your machine. Python standard library, no build step.

Set it up with one prompt

Paste one of these into Claude Code and answer its questions. It asks before anything that touches your accounts.

No notes yet, or you'd rather begin clean. Claude interviews you and writes your first notes.

Set up Brain (https://github.com/zacfink/brain) for me from scratch. Work through it step by step, tell me what each step is for in one line, and ask me before anything that touches my accounts.

1. Clone https://github.com/zacfink/brain.git into ~/Notes/.brain (keep anything already in ~/Notes), link ~/Notes/.brain/bin/brain into ~/.local/bin (create it, and add it to my shell profile's PATH if it isn't there), and read ~/Notes/.brain/README.md and FORMATS.md before going on.
2. Interview me briefly: my name, what I do, my active projects, people I work with, anything due in the next two weeks. Then write my first notes in the FORMATS.md shapes: me.md, now.md, one page per project, people pages, nudges.md, ideas.md, inbox.md and claude/habits.md (two or three habits from what I told you, status "proposed"). If you can see my projects folder, calendar or email, use them to fill gaps, and say what you took from where.
3. Connect yourself: add the SessionStart hook from the README to ~/.claude/settings.json (merge, don't overwrite), and add the README's standing instructions to my CLAUDE.md. Then run python3 ~/Notes/.brain/build.py.
4. Start the app with `brain` and check it opens at http://127.0.0.1:4747. On a Mac, ask me whether I want it as an app; if yes, run ~/Notes/.brain/mac/build.sh (needs Xcode's command line tools) to make ~/Applications/Brain.app.
5. Phone (ask me first): add ".brain/" to ~/Notes/.gitignore, create a PRIVATE GitHub repo "notes" with gh, add docs/notes-workflow.yml as .github/workflows/brain.yml plus phone/queue/.gitkeep, commit and push, and wait for the Action's first run to write phone/state.json.
6. Walk me through making the phone key (README → On your phone, step 3); I paste it to you. Then give me my one-tap install link: https://zacfink.github.io/brain/mobile/#c= followed by base64 of {"repo":"<me>/notes","token":"<key>"}. Tell me to open it in Safari, tap Share → Add to Home Screen, and treat the link like a password. Don't save the key anywhere.
7. Finish with a short list: what's set up, what I should try first, and anything that didn't work.

3. Skim my existing notes and tell me in a few lines what you found: active projects, people, anything due soon, recurring themes. Ask me at most 3 short questions to fill gaps.
4. Draft my Brain notes in the FORMATS.md shapes from what you found: me.md, now.md, one page per active project, people pages, nudges.md, ideas.md, inbox.md and claude/habits.md (two or three habits, status "proposed"). After each fact, note which original file it came from. Leave out anything that looks private (passwords, health, money) unless I say to include it. Show me the list of pages before writing them.
5. Connect yourself: add the SessionStart hook from the README to ~/.claude/settings.json (merge, don't overwrite), and add the README's standing instructions to my CLAUDE.md. Then run python3 ~/Notes/.brain/build.py.
6. Start the app with `brain` and check it opens at http://127.0.0.1:4747. On a Mac, ask me whether I want it as an app; if yes, run ~/Notes/.brain/mac/build.sh (needs Xcode's command line tools) to make ~/Applications/Brain.app.
7. Phone (ask me first): add ".brain/" to ~/Notes/.gitignore, create a PRIVATE GitHub repo "notes" with gh, add docs/notes-workflow.yml as .github/workflows/brain.yml plus phone/queue/.gitkeep, commit and push, and wait for the Action's first run to write phone/state.json. Then walk me through the phone key (README → On your phone, step 3) and give me my one-tap install link, as in the from-scratch setup. Don't save the key anywhere.

Or try it in 30 seconds

git clone https://github.com/zacfink/brain.git
cd brain
python3 app/server.py --notes example      # opens http://127.0.0.1:4747

example/ is a fictional student's notes. Python 3.9+, macOS, Windows and Linux.

On your phone

A home-screen app with the cover, Up next, notes to self, projects, ideas and capture. It works with your laptop off, using a private GitHub repo of yours as the backend. The setup prompt walks you through it and ends with a one-tap install link.
